Each `A<n>` below is the nth acceptance bullet in the corresponding immutable
[F01–F20 specification](../spec/root.md). File links identify runnable tests and
production callers. Historical gate counts are in [development evidence](../implementation/evidence.md);
the final complete gate and installation receipt belong in the [release checklist](release-checklist.md).
An issue closes only after its implementation is reachable from `main` and all
of its criteria have evidence. F15's already-closed client residual is #41.
