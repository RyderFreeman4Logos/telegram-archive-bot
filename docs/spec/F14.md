## Problem
Audio bytes can exist and be decodable in part while duration, indexes, size, or completeness remain wrong. Both synthesized and downloaded media need the same measurable output contract.
## Scope
Implement a Rust finalizer around FFmpeg/ffprobe with validated `audio_track` and `voice_note` profiles, explicit repair policies, atomic artifact publication, and ordered segmentation. Store a versioned manifest containing artifact ID, SHA-256, byte length, input and parent references, derivation key, producer and validation-tool versions, requested and effective profile, container, codec, MIME, channels, sample rate, measured duration_ms, validation status, and segment order/timeline offsets where applicable. Avoid lossy re-encoding when validated input or remuxed output already satisfies the profile.
## Dependencies
F03 (SQLite/CAS storage) and F07 (process supervision). F12 and F13 supply integration inputs but are not prerequisites: develop the finalizer against local synthetic fixtures. F15 consumes finalized artifacts only. Integrate the complete producer-to-delivery paths at F20.
## Acceptance criteria
- Fixtures cover normal MP3, incomplete MP3, concatenated MP3, missing/unreliable duration metadata, M4A, and OGG/Opus.
- Successful artifacts pass complete decoding and documented duration-consistency checks; invalid outputs cannot enter the reusable-artifact state.
- The concatenated-MP3 fixture demonstrates why remux success alone is insufficient.
- Every emitted file meets the configured final byte limit and quality floor; long media is segmented or fails clearly.
- Aborted processing leaves no published partial artifact, and artifact hashes match the exact published bytes.
- Segment order and subtitle/timeline offsets remain correct across boundaries.
## Evidence
[FFmpeg MP3 muxer](https://www.ffmpeg.org/ffmpeg-formats.html#mp3).
## Shared definition of done
Implemented behavior satisfies the criteria above, focused checks record actual evidence, relevant public documentation is updated, and no production secrets or user archive data enter the public code repository. Resolve dependency Spec-IDs to issue links while retaining the stable IDs.
