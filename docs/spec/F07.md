## Outcome
Download, extraction, speech, and FFmpeg subprocesses have one predictable execution contract.
## Implementation scope
Create a Rust process supervisor that takes explicit executable paths and argument arrays, a private job directory, a controlled environment, typed timeout/cancellation, and output/resource policies. Keep secrets out of irrelevant child environments.
Track process groups and terminate/reap descendants on cancellation or timeout. Bound captured logs and disk/output growth. Support structured progress/results without treating human console text as a stable API. Verify tool-produced paths are inside managed roots; reject traversal and symlink escapes.
Record executable versions and exit/termination status. Distinguish tool absence, invalid configuration, timeout, cancellation, nonzero exit, and invalid output. Provide a fake executable fixture for deterministic tests.
## Acceptance criteria
- Concurrent jobs using identical source filenames cannot collide.
- Arguments with spaces/metacharacters remain literal and cannot execute shell expressions.
- Cancelling a test tool kills its spawned child processes.
- Unbounded stdout/stderr and oversized output are bounded with clear diagnostics.
- Reported paths cannot escape the job directory.
- Environment/log redaction tests use synthetic sentinel secrets and confirm no leakage.
## Shared definition of done
Implemented behavior satisfies the criteria above, focused checks record actual evidence, relevant public documentation is updated, and no production secrets or user archive data enter the public code repository. Resolve dependency Spec-IDs to issue links while retaining the stable IDs.
