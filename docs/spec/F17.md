## Outcome
Operators can recover the complete retained dataset and understand the narrower guarantee of a Git text export.
## Implementation scope
Use a consistent SQLite backup mechanism plus a pinned inventory of all referenced retained blobs. Include schema/version metadata, hashes, byte lengths, and a backup manifest. Coordinate backup with publication and garbage collection. Restore credentials separately.
Restore into a new isolated location and verify database integrity, foreign keys, schema compatibility, and blob hashes before enabling workers. Pause external side effects by default. Reconcile interrupted leases and delivery states deliberately.
Implement a separate Git-only semantic importer for the current export schema: reconstruct entities, revisions, relations, views, and exported textual derivatives to the export checkpoint. Missing binary artifacts, recent unexported state, job history, and delivery receipts remain explicitly absent. This is not the optional legacy-format importer F22.
## Acceptance criteria
- A full backup restored into an empty directory matches all retained revisions, edges, views, and referenced blob digests.
- Missing/corrupt objects fail verification with specific diagnostics.
- A backup made during active work has a coherent reference inventory.
- Git-only reconstruction demonstrates the promised semantic equality and reports unavailable operational/binary data.
- Restore verification performs no Telegram send, Git push, or automatic old-job replay.
- Optional indexes are disposable and can be rebuilt.
- Operator commands and a repeatable disaster-recovery exercise are documented.
## Evidence
[SQLite online backup API](https://www.sqlite.org/backup.html) and [WAL](https://www.sqlite.org/wal.html).
## Shared definition of done
Implemented behavior satisfies the criteria above, focused checks record actual evidence, relevant public documentation is updated, and no production secrets or user archive data enter the public code repository. Resolve dependency Spec-IDs to issue links while retaining the stable IDs.
