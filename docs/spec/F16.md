## Outcome
A configured user archive repository receives portable, reproducible text and manifests without becoming a competing authoritative writer.
## Implementation scope
Write immutable export events in the same transaction as canonical changes. A serial projector renders exact revisions, relations, views, and text derivatives with versioned schemas, stable ordering, UTF-8/LF, safe relative paths, and deterministic formatting.
Export each source revision once. Views reference those revisions instead of permanently repeating their bodies. Expanded delivery documents remain reconstructable artifacts. Avoid timestamp noise unrelated to real observations.
Configure the archive destination independently of the public application repository. Commit only managed projection paths. Preserve unrelated staged/worktree changes. Identify commits with immutable event/checkpoint trailers and store local-commit status separately from remote-push status. Support one logical commit per knowledge-enrichment event.
Reconcile crash-after-commit through the event marker and expected hashes. Reconcile an uncertain push by inspecting the configured remote ref. Never force-push or silently overwrite external edits. Git failure must not invalidate stored sources.
## Acceptance criteria
- Two exports of identical data are byte-identical and produce an empty second diff.
- Every view resolves to its exact exported revisions or an explicit unavailable node.
- A/B/C export contains one canonical unchanged A body.
- Crashes after writing files and after committing recover without duplicate semantic commits.
- Push rejection and accepted-but-response-lost cases preserve separate local/remote status.
- Unrelated files or staged changes cannot enter an automatic commit.
- Git outages leave archived content usable and retryable projection work intact.
- Public code and archive destinations cannot coincide accidentally.
## Shared definition of done
Implemented behavior satisfies the criteria above, focused checks record actual evidence, relevant public documentation is updated, and no production secrets or user archive data enter the public code repository. Resolve dependency Spec-IDs to issue links while retaining the stable IDs.
