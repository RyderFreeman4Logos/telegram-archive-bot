## Outcome
Repeated submissions and delivery retries reuse valid expensive outputs without mixing incompatible context, models, or voices.
## Implementation scope
Define a versioned transform fingerprint from exact input revision/view references, ordered context, transform/prompt/schema versions, requested language, actual model/deployment revision and effective sampling configuration, tool versions, and synthesis/finalization settings.
Persist resolved voice mappings, rate, pitch, provider, and spoken-text hash. A context-sensitive summary keys on the full view; a source-local translation may reuse its source revision when its translation context is identical. A byte digest alone does not identify semantic work.
Coordinate in-flight identical work with database uniqueness/leases. Keep every run immutable; select a completed valid run explicitly. A force rerun creates a new run and never silently overwrites an old artifact. Degraded/partial results have distinct eligibility rules. Validate retained artifact hashes and ready state on reuse.
## Acceptance criteria
- Concurrent identical requests perform one selected transformation and retain independent authorized delivery requests.
- Changed model deployment, prompt, context, language, speaker assignment, or audio profile invalidates incompatible reuse.
- Repeated B/C views reuse A's source-local artifacts when appropriate without reusing an incompatible contextual summary.
- Upload retry invokes no translation or TTS.
- Missing/corrupt artifacts and incomplete runs cannot satisfy a successful cache hit.
- Force rerun preserves prior runs and records which result is selected.
- Tests use counting fake providers and observable outputs, not assertions against private cache implementation details.
## Shared definition of done
Implemented behavior satisfies the criteria above, focused checks record actual evidence, relevant public documentation is updated, and no production secrets or user archive data enter the public code repository. Resolve dependency Spec-IDs to issue links while retaining the stable IDs.
