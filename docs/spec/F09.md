## Outcome
Non-X inputs yield traceable source revisions and usable partial results.
## Implementation scope
Implement adapters for general HTML articles, ThreadReader pages, PDF URLs/documents, and Markdown/plain-text attachments. Reuse mature extraction helpers behind typed supervised boundaries where that preserves behavior and quality.
Record submitted/resolved URL, retrieval status, original artifact, extractor identity, language, completeness, and normalized content. Keep webpage canonicalization conservative. Define size/content-type/redirect policies, including protection from arbitrary submitted URLs reaching private-network services.
For PDFs, validate and retain the original independently of text extraction. If extraction fails, the PDF is still available for authorized document delivery and the text workflow is partial/failed. Detect text encoding, sanitize display filenames, and preserve source Markdown semantics before creating a separate speech representation.
## Acceptance criteria
- HTML, ThreadReader, text PDF, extraction-failing PDF, Unicode Markdown, and text attachments have focused fixtures.
- A valid PDF survives extraction failure and is not falsely marked translated.
- Distinct semantic query URLs remain distinct; hostile redirect/path/oversize fixtures fail safely.
- Same-named attachments in concurrent jobs remain isolated.
- Source text, raw artifact, and derived text have separate provenance and states.
- Fallback extraction reports its chosen provider and quality instead of silently discarding the original.
## Shared definition of done
Implemented behavior satisfies the criteria above, focused checks record actual evidence, relevant public documentation is updated, and no production secrets or user archive data enter the public code repository. Resolve dependency Spec-IDs to issue links while retaining the stable IDs.
